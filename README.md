## About Me

I'm a full-stack developer interested in quantitative finance, financial data, and analytical software. I enjoy turning a research question into a practical workflow: preparing data, implementing calculations, and presenting the evidence in a clear interface.

- **Building:** web applications and data-focused research tools
- **Exploring:** market data, factor analysis, risk measurement, and model evaluation
- **Learning:** financial engineering, statistics, and reliable software design

## Areas I Explore

<details>
<summary><strong>Quantitative research</strong></summary>

I explore how financial data can support transparent analysis, including data-quality checks, technical and fundamental features, factor research, portfolio risk, and out-of-sample evaluation. I aim to distinguish calculated evidence from assumptions and unvalidated hypotheses.

</details>

<details>
<summary><strong>Software and visualization</strong></summary>

I work on full-stack applications, local-first research workflows, data processing, and interactive visualizations. I value tools that show their inputs and calculation logic so users can inspect how an output was produced.

</details>
